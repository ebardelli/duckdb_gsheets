DuckDB GSheets

A DuckDB extension for reading and writing Google Sheets with SQL.

This is a fork of the DuckDB GSheets extension (source) maintained by Evidence. It publishes builds for DuckDB 2.0 until those are available upstream. This project is not affiliated with Google or DuckDB.

Install

DuckDB 2.0

Builds for DuckDB 2.0 are published here as a signed extension repository:

SET allow_extension_repositories = 'allowed';
CREATE EXTENSION REPOSITORY gsheets_fork WITH PREFIX 'https://ebardelli.github.io/duckdb_gsheets/extensions';
INSTALL AND LOAD gsheets FROM gsheets_fork;

CREATE EXTENSION REPOSITORY prints the fingerprint of the signing key it pinned. Check that it matches sha256:30a99a8ad18afde28756024575259ce6a65eb53232d91790efaff11035fdcacc. The repository persists across sessions, so later sessions only need LOAD gsheets FROM gsheets_fork;.

DuckDB 1.5 and earlier

Use the community build, maintained upstream:

INSTALL gsheets FROM community;
LOAD gsheets;

DuckDB-WASM

DuckDB-WASM can't install from external extension repositories yet, but an app that embeds it can load the build directly. See the DuckDB-WASM instructions.

Quick start

-- Sign in with your Google account in the browser
CREATE SECRET (TYPE gsheet);

-- Read a sheet
FROM read_gsheet('https://docs.google.com/spreadsheets/d/11QdEasMWbETbFVxry-SsD8jVcdYIT1zBQszcF84MdE8/edit');

-- Write a table to a sheet
COPY my_table TO 'https://docs.google.com/spreadsheets/d/11QdEasMWbETbFVxry-SsD8jVcdYIT1zBQszcF84MdE8/edit' (FORMAT gsheet);

The full documentation covers the other ways to authenticate (your own OAuth client, refresh tokens for pipelines, service accounts), reading specific sheets and ranges, and the write options.
